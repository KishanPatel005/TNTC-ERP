Construction ERP - Needed Details

1) Application URL
- http://localhost/TNTC/login.php

2) First-time Admin user (to be created on first run)
- Name: System Administrator
- Email: admin@example.com
- Password: Admin@12345

How to use these credentials:
- On first launch, the login screen detects that there are no users and will present a form to create the first Admin.
- Enter the Name, Email, and Password above, submit the form, and you will be logged in as Admin.

3) Import order
- Create database: construction_erp
- Import schema: sql_dump.sql
- Import data: dummydata.sql

4) Sample Data Summary (from dummydata.sql)
- Projects: 3 sample projects
- Tasks: Foundation/Structure/Finishing for Residential Complex A - Phase 2 with sub and ground tasks
- Vendors: ConcreteMixers Inc., MegaSteel Traders
- Stock: Cement, Sand, Steel Rod 12mm, Bricks with initial quantities
- Purchase Orders: PO-2025-001 (ConcreteMixers Inc.), PO-2025-002 (MegaSteel Traders)
- GRN: GRN-2025-001 (partial receipt for PO-2025-001)

5) Suggested test flows
- Create Admin (as above) and login
- Navigate to Projects and verify seeded projects
- Go to Tasks and verify seeded task hierarchy
- Check Stock, POs, and GRNs; confirm stock levels reflect GRN IN transactions
- Create a Material Request and Approve it to see stock OUT and Stock Logs update
- Mark Attendance and run Salary calculation for the current month

6) Troubleshooting
- If login doesn’t show the Admin creation form, confirm the users table is empty
- If DB connection fails, update DB credentials in config.php and ensure MySQL is running
